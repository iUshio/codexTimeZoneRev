# v0.2.4 · macOS DreamSkin 兼容启动修复

macOS 启动器现在会使用 DreamSkin 管理器安装在当前用户目录的引擎。「保存并启动」和「重新注入皮肤」都会加载这份引擎里的主题与窗口识别规则。已安装的原版引擎和自行调整过的引擎均可使用。

首次使用时，请先在 DreamSkin 管理器中完成安装。如果引擎缺少启动所需的文件，启动器会指出具体路径，并提示通过管理器修复。

要排查启动耗时，可查看 `~/Library/Application Support/com.fei-away.codextimezone/dream-skin-timing.log`。每次记录包含引擎路径、客户端接口就绪耗时、皮肤脚本耗时和校验结果。脚本输出仍保存在同目录的 `dream-skin.log`。
